The daily journal

30 days. One commit at a time.

Write a few honest lines after each session: what you learned, what was tricky, and what you'll try tomorrow.

DAY 01

Start with structure

Set up the repository and understand the main sections of a semantic HTML page.

Today's learning prompt

What do header, nav, main, section, and footer communicate to the browser and assistive technology? Add one note in your README.

DAY 02

Make it feel intentional

Practice spacing, typography, color, and reusable CSS variables.

Today's learning prompt

Change the accent color and spacing scale. Which CSS custom properties let you update the whole site quickly?

DAY 03

Make it responsive

Use a mobile viewport and media queries to make the layout work on small screens.

Today's learning prompt

Resize the browser. Find one layout that feels cramped, then use a media query to improve it.

Keep adding entries each day. Your journal becomes proof of the process, not just the final result.
